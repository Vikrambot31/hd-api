# 🔧 ЗАПУСТИТЬ ДИАГНОСТИКУ (пошагово)

## Шаг 1: Очистить кэш браузера
1. Откройте браузер с calculator_web.html
2. **Нажмите: `Ctrl+Shift+R`** (Windows/Linux) или **`Cmd+Shift+R`** (Mac)
   - Это Hard Refresh, очистит весь кэш
3. Подождите, пока страница полностью загрузится

---

## Шаг 2: Открыть консоль браузера
1. **Нажмите: `F12`** или **`Ctrl+Shift+I`** (Windows/Linux)
2. Или **`Cmd+Option+I`** (Mac)
3. Перейдите на вкладку **"Console"** (обычно вторая вкладка)

Должна выглядеть вот так:
```
┌─────────────────────────────────────┐
│ Console Errors Sources Network ...  │  ← вкладки
├─────────────────────────────────────┤
│                                     │
│ (console очищена, текста нет)      │
│                                     │
└─────────────────────────────────────┘
```

---

## Шаг 3: Ввести тестовую дату

В левой части страницы найдите форму **"Дата рождения"** и заполните:

| Поле | Значение |
|------|----------|
| **День** | `24` |
| **Месяц** | `1` |
| **Год** | `1922` |
| **Час** | `7` |
| **Минуты** | `25` |
| **Секунды** | `0` |
| **Часовой пояс** | `UTC+3 (Москва)` |

Визуально должно выглядеть так:
```
┌─ Дата рождения ──┐
│ День   │ 24      │
│ Месяц  │ 1       │
│ Год    │ 1922    │
│ Час    │ 7       │
│ Минуты │ 25      │
│ Сек    │ 0       │
└─────────────────┘
Часовой пояс: [UTC+3 (Москва)]
```

---

## Шаг 4: Запустить расчет

1. **Нажмите кнопку:** `Рассчитать карту`
2. **Смотрите на консоль** → должны начать появляться логи

Примерно через 2-5 секунд в консоли появятся строки типа:

```
PERS: [1, 7, 18, 26, 31, 37, 41, 48, 49, 52, 57, 60]
DES: [6, 7, 18, 27, 28, 37, 39, 44, 46, 48, 57]
[DEBUG] ch_1_8: ca=black, cb=null
[DEBUG] ch_1_8: gradient mode
  c1: #111111 (gate 1)
  c2: #888888 (gate 8)
  ...
```

Посмотрите на **центральную часть страницы** — bodygraph (круглая диаграмма):

- [ ] Видно **solid black линию** между ворот 7 и 31 (channel 7-31)
- [ ] Видно **чёрно-серую линию** между ворот 1 и 8 (channel 1-8)

## Шаг 7: Скопировать результаты

Когда ВСЕ логи появятся в консоли:

1. **Выделите весь текст в консоли:**
   - Нажмите `Ctrl+A` (выделить все)
2. **Скопируйте:**
   - Нажмите `Ctrl+C` (скопировать)
3. **Сохраните** в текстовый файл или отправьте

Ключевые строки для копирования (от и до):
```
⬇️ НАЧАЛО
PERS: [1, 7, 18, 26, 31, 37, 41, 48, 49, 52, 57, 60]
...
[DEBUG] === End DOM verification ===
⬆️ КОНЕЦ
```

## Шаг 8: Дополнительная диагностика (если нужна)

### Если логи показывают **неверные значения ca/cb**
→ Проблема в API или нормализации ворот

**Проверьте:** Первые строки логов должны быть:
```
PERS: [1, 7, 18, 26, 31, 37, 41, 48, 49, 52, 57, 60]
DES: [6, 7, 18, 27, 28, 37, 39, 44, 46, 48, 57]
```
Если другие числа → запишите какие.

---

### Если логи **правильные, но каналы не видны в браузере**
→ Проблема в CSS или перетирании стилей

**Что делать:**
1. В консоли браузера найдите canvas/bodygraph
2. Правая кнопка на невидимом канале → **Inspect**
3. В DevTools посмотрите вкладку **Styles**
4. Ищите, какие CSS-правила применены к `<path>`
5. Посмотрите, есть ли `display: none` или другие скрывающие стили

---

### Если логи **DOM verification показывают другой stroke**
→ Стиль **перетирается после вставки SVG**

**Пример проблемы:**
```
[DEBUG] ch_1_8: gradient mode
  stroke: url(#grad_ch_1_8)     ← правильно установлен

[DEBUG] ch_1_8 in DOM:
  attr stroke: #7f89ad          ← ❌ ПЕРЕПИСАН НА БАЗОВЫЙ!
```

Это значит, что между строками 247 и 335 в коде что-то переписывает stroke.

## Если что-то не сработало

### Проблема: Логи не видны совсем
```
↳ Решение 1: Hard Refresh еще раз (Ctrl+Shift+R)
↳ Решение 2: Полностью закрыть браузер и открыть заново
↳ Решение 3: Очистить полностью кэш браузера (Settings → Clear cache)
```

### Проблема: Видно очень много логов (весь список 36 каналов)
```
↳ Это НЕПРАВИЛЬНО — логи должны быть только для ch_1_8, ch_7_31, ch_46_29
↳ Причина: старая версия кода в кэше
↳ Решение: Hard Refresh (Ctrl+Shift+R) еще раз
```

### Проблема: Ошибка в консоли вместо логов
```
↳ Запишите текст ошибки полностью
↳ Укажите номер строки в коде
↳ Это поможет понять, где проблема
```

### Проблема: Калькулятор вообще не запускается
```
↳ Проверьте: вы открыли через HTTP-сервер? (не file://)
↳ В Developer Tools → Network → посмотрите на статусы запросов
↳ Есть ли красные ошибки (статус 404, 500)?
```
