## Проверочные вопросы

### Блок 1: Правильность API
- [ ] В консоли видно: `PERS: [1, 7, 18, 26, 31, 37, 41, 48, 49, 52, 57, 60]`?
- [ ] В консоли видно: `DES: [6, 7, 18, 27, 28, 37, 39, 44, 46, 48, 57]`?
- **Если НЕТ** → Проблема в API, не в рендере

### Блок 2: Правильность логики цветов
- [ ] `ch_1_8: ca=black, cb=null`?
- [ ] `ch_7_31: ca=black, cb=black`?
- [ ] `ch_46_29: ca=red, cb=null`?
- **Если НЕТ** → Проблема в `gateColorFromSets()`, не в отрисовке

### Блок 3: Правильность stroke/width/filter
- [ ] Для `ch_1_8`: `stroke: url(#grad_ch_1_8)`?
- [ ] Для `ch_7_31`: `stroke: #111111`?
- [ ] Для `ch_46_29`: `stroke: url(#grad_ch_46_29)`?
- [ ] Все три имеют: `stroke-width: 34` и `filter: url(#activeGlow)`?
- **Если НЕТ** → Проблема в логике установки атрибутов

### Блок 4: DOM-целостность
- [ ] После вставки SVG логи в `[DEBUG] === DOM verification ===` совпадают с вышестоящими?
- **Если НЕТ** → Stroke/width/filter **перетираются** после вставки

### Блок 5: Визуальное отображение
- [ ] На экране видны:
  - `ch_7_31` как **solid black** линия между ворот 7 и 31?
  - `ch_1_8` как **чёрная → серая** линия между ворот 1 и 8?
  - `ch_46_29` как **красная → серая** линия между ворот 46 и 29?
- **Если НЕТ** → Проблема в CSS/фильтрах или градиентах не применились

## Вероятные сценарии и решения

### Сценарий 1: Логи в консоли не видны совсем
→ Версия скрипта не обновилась
- Решение: Hard refresh (Ctrl+Shift+R или Cmd+Shift+R)

### Сценарий 2: Логи показывают правильные значения, но каналы не видны
→ CSS перетирает stroke
- Решение: Откройте DevTools → Inspect element на `<path id="ch_1_8">` → Посмотрите Styles
- Найдите, какое правило перезаписывает stroke (может быть фильтр, clip-path, display: none)

### Сценарий 3: Логи показывают gradient, но в браузере это solid color
→ Градиент не применяется (не созданы stop-элементы)
- Решение: Откройте DevTools → Elements → Найдите `<linearGradient id="grad_ch_1_8">` → Есть ли `<stop>` элементы внутри?

### Сценарий 4: ch_1_8 имеет ca=null (вместо black)
→ Gate 1 не распознана как активная
- Решение: Проверьте normalizegateArray() → может быть, gates приходят как строки вместо чисел?
