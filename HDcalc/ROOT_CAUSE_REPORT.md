# 📋 ОТЧЁТ: ROOT CAUSE — Gate 45 отсутствовал в расчётах

**Дата:** 2026-04-07
**Статус:** ✅ ИСПРАВЛЕНО — все тесты проходят

---

## 1. Root Cause (корневые причины)

### Причина 1 — Основная: Южный Узел не участвовал в расчётах ❌→✅
В оригинальном `hd_api.py` **Южный Узел (South Node, ☋)** не вычислялся и не включался в `personality_gates` / `design_gates`.

Gate 45 для кейса **20.05.1974 15:25 Киев** приходит именно от **Южного Узла Personality**:
```
S.Node Personality: lon = 79.477°  →  Gate 45.3 (линия 3)
```
*(S.Node = N.Node + 180° = 259.477° + 180° = 79.477°)*

### Причина 2 — Вторичная: `lookup_gate_data` была определена после `load_lookup` ❌→✅
Функция `lookup_gate_data` вызывалась в sanity-check внутри `load_lookup()`, но была определена **ниже по файлу** — Python NameError при запуске.

### Причина 3 — Вторичная: Неправильные контрольные точки в `validate_lookup.py` ❌→✅
Файл содержал `(24.4, 44)` и `(11.5, 45)` — оба значения неправильны согласно эталону. Это заставляло CMD показывать **ложное WARNING** при каждом запуске.
