✅ БЫСТРЫЙ СТАРТ (рекомендуется)
───────────────────────────────────────────────────────────────────────────

  1. Двойной клик на файл:
     
     📄 start_local_server.cmd
     
  2. Откроется окно с проверками. Подождите 5-10 секунд.
  
  3. Браузер откроется автоматически.
  
  4. Введите дату и нажимайте "Рассчитать".


❓ ЧТО ДЕЛАЕТ start_local_server.cmd
───────────────────────────────────────────────────────────────────────────

  [1] Проверяет установку Python
  [2] Устанавливает зависимости (Flask, pyswisseph и т.д.)
  [3] Запускает локальный сервер расчетов (порт 10000)
  [4] Запускает веб-сервер (порт 8000)
  [5] Открывает браузер на http://localhost:8000/calculator_web.html


⚠️ ЕСЛИ НЕ РАБОТАЕТ
───────────────────────────────────────────────────────────────────────────

❌ "ERROR: Python is not installed or not in PATH!"
   
   Решение:
   • Скачайте Python с https://www.python.org/downloads/
   • При установке ОБЯЗАТЕЛЬНО отметьте "Add Python to PATH"
   • Переустановите или добавьте вручную в переменные окружения


❌ Окно закрывается сразу или ошибка про порт
   
   Решение:
   • Зайдите в папку в PowerShell и запустите:
     
     powershell -ExecutionPolicy Bypass -File start_local_server.ps1
     
   • Это покажет детальный лог ошибки


❌ Долгая загрузка расчета (медленнее 5 секунд)
   
   Решение:
   • Убедитесь, что запущен локальный сервер (два окна открыты)
   • Откройте http://localhost:10000/api/calc в браузере
   • Если страница не открывается = Python API не запустился


🔧 АЛЬТЕРНАТИВНЫЕ ВАРИАНТЫ
───────────────────────────────────────────────────────────────────────────

Вариант 1 (PowerShell напрямую):
  • Откройте PowerShell в папке проекта
  • Выполните:
    powershell -ExecutionPolicy Bypass -File start_local_server.ps1


Вариант 2 (вручную в двух окнах):
  
  Окно 1 (Python API):
    python hd_api.py
    (должно вывести "Running on http://0.0.0.0:10000")
  
  Окно 2 (веб-сервер):
    powershell -ExecutionPolicy Bypass -File start_local_server.ps1


Вариант 3 (установка зависимостей вручную):
  
  python -m pip install -r requirements.txt


📝 ФАЙЛЫ В ЭТОЙ ПАПКЕ
───────────────────────────────────────────────────────────────────────────

  start_local_server.cmd        ← ЗАПУСКАЙТЕ ЭТОТ (главный файл)
  start_local_server.ps1        ← Скрипт PowerShell (запускается автоматически)
  hd_api.py                     ← Python API (расчеты)
  calculator_web.html           ← Веб-интерфейс
  requirements.txt              ← Зависимости Python


✅ ГОТОВО
───────────────────────────────────────────────────────────────────────────

Если все работает:
  • Браузер откроется на http://localhost:8000/
  • Введите дату рождения
  • Нажмите "Рассчитать"
  • Получайте результат за 1-2 секунды!

Если вопросы или ошибки — проверьте логи в окне с ошибками.
