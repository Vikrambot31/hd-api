  БЫСТРЫЙ СТАРТ: Debug режим для диагностики каналов
═══════════════════════════════════════════════════════════════════

ШАГ 1: Hard refresh браузера
  Нажмите: Ctrl+Shift+R (Windows/Linux) или Cmd+Shift+R (Mac)
  → Очистить кэш и загрузить новую версию bodygraph_renderer.js

ШАГ 2: Откройте консоль браузера
  Нажмите: F12 или Ctrl+Shift+I
  → Перейдите на вкладку "Console"

ШАГ 3: Введите ТЕСТОВУЮ ДАТУ
  День:    24
  Месяц:   1
  Год:     1922
  Час:     7
  Минуты:  25
  UTC:     UTC+3 (Москва)

ШАГ 4: Нажмите "Рассчитать карту"
  → Смотрите логи в Console

ШАГ 5: Найдите логи [DEBUG]
  Ищите строки вида:
    [DEBUG] ch_1_8: ca=black, cb=null
    [DEBUG] ch_7_31: ca=black, cb=black
    [DEBUG] ch_46_29: ca=red, cb=null

ЕСЛИ ВИДИТЕ ЛОГИ:
  → Проверьте значения по DIAGNOSTIC_CHECKLIST.md
  → Скопируйте весь блок логов и отправьте

ЕСЛИ ЛОГИ НЕ ВИДНЫ:
  → Hard refresh (Ctrl+Shift+R) еще раз
  → Очистите кэш браузера полностью

═══════════════════════════════════════════════════════════════════

ОЖИДАЕМЫЕ РЕЗУЛЬТАТЫ:

Логи должны содержать:
✓ PERS: [1, 7, 18, 26, 31, 37, 41, 48, 49, 52, 57, 60]
✓ DES: [6, 7, 18, 27, 28, 37, 39, 44, 46, 48, 57]

✓ ch_1_8:  gradient mode (black → grey)
✓ ch_7_31: same color mode (solid black)
✓ ch_46_29: gradient mode (red → grey)

Все три должны иметь:
✓ stroke-width: 34
✓ filter: url(#activeGlow)
