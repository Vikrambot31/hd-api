## ❌ ЕСЛИ НЕ РАБОТАЕТ

### Проблема 1: "Python is not installed"
```
Решение: Установите Python
→ https://www.python.org/
→ При установке: CHECK "Add Python to PATH"
```

### Проблема 2: "Could not install dependencies"
```
Решение: Установите вручную
→ Откройте PowerShell в папке web_calculator
→ Выполните:
   python -m pip install flask flask-cors swisseph
```

### Проблема 3: "Port 8000 already in use"
```
Решение: Измените порт в start_local_server.ps1
→ Найдите строку: $port = 8000
→ Измените на: $port = 8001
→ Запустите снова
```

### Проблема 4: Браузер не открывается
```
Решение: Откройте вручную
→ Перейдите на: http://localhost:8000
```

## 💻 ТЕХНИЧЕСКИЕ ДЕТАЛИ
