## 🎬 ПЛАН ДЕЙСТВИЙ

### Фаза 1: Запуск (2-5 минут)
1. Прочитайте `START_HERE.md`
2. Двойной клик на `start_local_server.cmd`
3. Дождитесь открытия браузера

### Фаза 2: Обнаружение проблем (если есть)
1. Откройте `BUG_ANALYSIS.md`
2. Проверьте известные ошибки
3. Если есть другие проблемы → `LAUNCHER_FIX_REPORT.md`

### Фаза 3: Исправление ворот (на неделю)
1. Прочитайте `QUICK_FIX_GUIDE.md` полностью
2. Найдите исходный файл `!Рассчеты_upd_v.5.xlsx`
3. Пересчитайте `fullhd_lookup.json`
4. Протестируйте на примерах

## 🎓 ОБУЧЕНИЕ

Для лучшего понимания проекта:

1. **Что такое Human Design?**
   - Система астрологических расчётов
   - 64 ворота, каналы, центры

2. **Как работает калькулятор?**
   - Берёт дату рождения → вычисляет положение планет
   - Положение планет → таблица ворот → график тела

3. **Где ошибка?**
   - Таблица ворот (fullhd_lookup.json) неправильная
   - Долготы вычисляются правильно
   - Проблема в соответствии долгота → ворота
